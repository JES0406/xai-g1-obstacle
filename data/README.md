# data/

Published subset of the rollout dataset: the `.npz` episodes saved with image and
segmentation mask (20 per evaluation set), generated by `src/rollout.py` with the
seeds in `configs/sets.yaml`. Full logs (`data/raw/`) are regenerated, not committed.
If the subset exceeds GitHub's size limits it goes to a release of this repo.
Dataset description (origin, size, types, preprocessing): added after generation.
